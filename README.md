# 🃏 撲克牌心臟病 - 1v3 大亂鬥！

## 📖 專案簡介

準備好測試你的反應極限了嗎？來一場刺激的撲克牌對決吧！🔥

這是一個使用 C# Windows Forms 開發的單機版經典撲克牌遊戲——**心臟病 (Slapjack)**！在這款遊戲中，你將獨挑大樑，迎戰三位反應時間深不可測的 AI 機器人 🤖！

遊戲節奏緊湊刺激，玩家與機器人會輪流出牌並依序喊出 1 到 13 的數字。當**喊出的數字與牌面真實點數完全相符**時，心臟病瞬間發作！💥 你必須展現驚人的動態視力與手速，第一時間按下「拍牌」按鈕！最慢拍牌的倒楣鬼必須含淚收下桌面所有的牌 😭。

只要你能率先清空手中的牌，並在最後一次心臟病發作時成功存活下來，你就能成為這場大亂鬥的最終贏家！🏆 相信你一定可以把機器人電得落花流水啦！(ง •̀_•́)ง

## 🚀 執行與遊玩說明

為了讓遊戲順利運作並獲得最完整的聲光體驗，請跟著以下步驟設定與執行喔！✨

### 1. 準備開發環境

* 請確保你的電腦已安裝 **Visual Studio** 以及對應的 **.NET 桌面開發環境**。
* 將這段程式碼建立為一個 Windows Forms App 專案，並將主程式碼貼入 `Form1.cs` 中。

### 2. 準備遊戲素材 (這點超重要！🌟)

程式碼中設計了動態載入圖片與音效的機制，請確保你的專案目錄內有以下檔案，否則系統會啟動防呆機制（顯示紅底與發出系統嗶聲）：

* **🃏 撲克牌圖片**：
準備 52 張撲克牌圖片，檔名請命名為 `pic1.png` 到 `pic52.png`。
*(邏輯說明：1~4 代表 A，5~8 代表 2... 以此類推)*
**放置位置**：將圖片放在專案資料夾根目錄，或是建置後的 `.exe` 執行檔所在資料夾。
* **🎵 音效檔案**：
請建立一個名為 `Sounds` 的資料夾，並放入以下 `.wav` 音效檔來豐富遊戲體驗：
* `play.wav` (出牌音效)
* `heart.wav` (心臟病觸發警告音效)
* `slap.wav` (拍牌音效)
* `lose.wav` (最慢拍牌的懲罰音效)
* `win.wav` (勝利歡呼音效)
**放置位置**：與執行檔同層級的 `Sounds` 資料夾，或專案根目錄下的 `Sounds` 資料夾。



### 3. 開始挑戰！🎮

1. 在 Visual Studio 中按下 **F5** 或點擊「開始」編譯並執行專案。
2. **你的回合**：當畫面上方提示「換你出牌了！」時，點擊畫面下方的 **【出牌】** 按鈕。
3. **心臟病發作**：請緊盯桌面中央的撲克牌與提示文字！當「喊出的數字」與「出牌點數」一樣時，畫面會出現紅色警告 💥。
4. **極限反殺**：立刻狂點 **【拍牌！】** 按鈕，千萬別當最後一個！

祝你好運，成為真正的撲克牌大師吧！💪✨
