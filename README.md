#  撲克牌心臟病 - 1v3 大亂鬥！

## 專案簡介

準備好測試你的反應極限了嗎？來一場刺激的撲克牌對決吧！🔥💥🦽

這是一個單機版經典撲克牌遊戲——**心臟病 (Slapjack)**！

遊戲節奏緊湊刺激，玩家與機器人會輪流出牌並依序喊出 1 到 13 的數字。當**喊出的數字與牌面真實點數完全相符**時，心臟病瞬間發作！💥 你必須展現驚人的動態視力與手速，第一時間按下「拍牌」按鈕！最慢拍牌的倒楣鬼必須含淚收下桌面所有的牌 😭。

只要你能率先清空手中的牌，並在最後一次心臟病發作時成功存活下來，你就能成為這場大亂鬥的最終贏家！🏆 相信你一定可以把機器人電得落花流水啦！(ง •̀_•́)ง

##  執行與遊玩說明

2. **你的回合**：當畫面上方提示「換你出牌了！」時，點擊畫面下方的 **【出牌】** 按鈕。
3. **心臟病發作**：請緊盯桌面中央的撲克牌！當「喊出的數字」與「出牌點數」一樣時，畫面會出現紅色警告 💥。
4. **極限反殺**：立刻狂點 **【拍牌！】** 按鈕，千萬別當最後一個！
